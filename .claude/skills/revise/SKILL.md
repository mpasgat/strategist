# Пересмотр

1. Сохрани новый материал в кэш: `python tools/ingest.py <файл> --slug <имя>` (или запиши слова человека в `project/sources/notes.md` с датой).
2. Найди затронутые записи: `grep` по `state/claims.jsonl` и по ключевым словам. Новые сведения занеси как новые claims.
3. Старые записи, которые больше не верны, отметь `"status": "superseded", "reason": "...", "replaced_by": "Cxxx"`. Не удаляй их.
4. Запусти `python tools/lint_claims.py output/strategy.md output/final.md` (`final.md` указывай, только если он уже есть): линтер покажет каждую строку, опирающуюся на отозванный claim. Это и есть список затронутых выводов.
5. Пересчитай только затронутые расчёты через `tools/calc.py` и исправь только эти строки.
6. Скажи человеку в 3–5 строках: что изменилось, какие выводы поменялись, меняется ли рекомендация. Если меняется выбор варианта, это снова СТОП 2.
7. Допиши в `state/log.md`: дата, новые сведения, отозванные claims, изменённые выводы.
